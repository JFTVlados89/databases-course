# Домашнее задание №1. От бизнес-требований к физической модели

**Вариант:** №1. Онлайн-курсы (EdTech)

## Задание 1. Концептуальная модель

В данной системе онлайн-образования выделены следующие основные сущности:
* User (Пользователь) — участник платформы. Хранит информацию как о студентах, так и о преподавателях, так как их разделение будет происходить через атрибут роли.
* Course (Курс) — образовательная единица. Эти курсы создают преподаватели, а студенты их проходят.
* Lesson (Урок) — составная часть курса. Каждый курс состоит из нескольких таких уроков.
* Enrollment (Зачисление) — связующая сущность, которая соединяет студентов и курсы. В ней отслеживается общий прогресс обучения студента по конкретному курсу.
* Review (Отзыв) — сущность для хранения обратной связи. Здесь хранятся текстовые отзывы и оценки от 1 до 5, которые студенты оставляют к курсам.

Схема связей:
* Между User (Преподаватель) и Course: связь один ко многим (1:N). Один преподаватель может создать множество курсов.
* Между Course и Lesson: связь один ко многим (1:N). Один курс включает в себя много уроков.
* Между User (Студент) и Course через Enrollment: связь многие ко многим (M:N). Студент может учиться на нескольких курсах, а на одном курсе может быть много студентов.
* Между User (Студент) и Review: связь один ко многим (1:N). Один студент может оставить множество отзывов к разным курсам.
* Между Course и Review: связь один ко многим (1:N). У одного курса может быть много отзывов от разных студентов.
